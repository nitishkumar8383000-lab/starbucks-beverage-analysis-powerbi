# ☕ Starbucks Beverage Analysis Dashboard – Power BI

An interactive **Starbucks Beverage Analysis Dashboard** built using **Microsoft Power BI** to analyze beverage categories, calories, sugar, caffeine, and other nutritional insights.

## 📊 Dashboard Preview

The dashboard provides a clean and interactive view of Starbucks beverage data with KPI cards, charts, filters, and category-level analysis.

## 🎯 Project Objectives

* Analyze Starbucks beverage categories
* Compare average calories, sugar, and caffeine
* Identify beverages with the highest caffeine levels
* Understand beverage category distribution
* Create an interactive and professional Power BI dashboard
* Convert raw data into meaningful business insights

## 📌 Key Features

* **Total Beverages:** 33
* **Average Sugar:** 32.90
* **Average Calories:** 193.78
* **Average Caffeine:** 82
* Average Calories by Beverage Category
* Average Caffeine by Category
* Beverage Category Distribution
* Starbucks Global Presence
* Top 5 Highest Caffeine Beverages
* Interactive Protein Range filter
* Beverage Preparation filter

## 📈 Dashboard Insights

The dashboard makes it easy to identify differences between beverage categories and compare nutritional characteristics. Coffee-based beverages show higher caffeine levels, while different beverage categories vary significantly in calories and sugar content.
